厚い記述

あついきじゅつ

thick description

ジャンル：社会社 会

ひとことで

人の行動を、表面の動きだけでなく、その場の文脈や意味まで含めて描き出すこと。

由来

人類学者クリフォード・ギアツが、1973年の著書『文化の解釈学』で広めた。哲学者ギルバート・ライルが挙げた例を借り、まぶたがただけいれんしたのか、合図のウインクなのか、ウインクのまねでからかっているのかは、目の動きだけでは区別できず、その意味を読み解くことが文化の研究だと論じた。

見え方が変わるところ

同じ「既読スルー」でも、忙しいのか、怒っているのか、気を遣っているのかは文脈しだい。データや行動の記録だけで、人を分かった気にならないための言葉。

使ってみる

「アンケートの数字だけじゃ分からない。厚い記述が要るから、現場で話を聞いてこよう」
